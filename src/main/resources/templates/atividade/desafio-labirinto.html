Desafio do Labirinto

Labirinto no chão com bifurcações: siga o caminho verde se a condição for verdadeira, o vermelho se for falsa.

Conceito
Condicionais
Tempo estimado
25 minutos
Idade
6 a 10 anos
Espaço
Pátio ou sala grande

Objetivo de aprendizagem

Compreender o conceito de condicional: bifurcações onde a escolha do caminho depende de uma condição ser verdadeira ou falsa. As crianças vivenciam corporalmente o fluxograma de uma estrutura Se/Senão.

Passo a passo

  1. Construa o labirinto

    Com fita crepe, crie um caminho com 2 ou 3 bifurcações. Em cada bifurcação, pendure um cartão com uma condição: ex. "Você está usando algo azul?"

  2. Marque os caminhos

    Fita verde = caminho do SIM. Fita vermelha = caminho do NÃO. Ambos levam a saídas diferentes.

  3. Percorra o labirinto

    Cada criança entra no labirinto e, em cada bifurcação, verifica se a condição é verdadeira para si. O caminho percorrido é único para cada aluno.

  4. Troca de condições

    Peça que a turma proponha novas condições para as bifurcações. O labirinto recebe novas fitas e o percurso muda.

  5. Reflexão

    Desenhe no quadro o labirinto como um fluxograma. Mostre que é exatamente o que um computador faz ao executar um Se/Senão.

Dica para o professor Use condições divertidas e pessoais: "Tem irmão?" ou "Gosta de cachorro?" — isso torna a experiência mais imersiva.

Materiais

  • Fita crepe verde e vermelhaPara os caminhos de SIM e NÃO.
  • Cartões de condiçãoUm por bifurcação com a pergunta escrita.
  • Espaço amploPátio ou sala com mesas afastadas.

Conceito de computação

Condicional (Se/Senão) é uma bifurcação no algoritmo: dependendo se uma condição é verdadeira ou falsa, o programa segue um caminho diferente.
