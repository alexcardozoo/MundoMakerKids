Ciranda Algorítmica

A brincadeira de roda vira um programa com loops aninhados e condições que mudam a coreografia.

Conceito
Loop aninhado
Tempo estimado
25 minutos
Idade
6 a 10 anos
Espaço
Pátio ou sala

Objetivo de aprendizagem

Vivenciar corporalmente o conceito de loop aninhado — um loop dentro de outro. A ciranda tem um ritmo que se repete (loop externo) e dentro de cada volta há movimentos que também se repetem (loop interno), com uma condição que muda o gesto.

Passo a passo

  1. Monte a ciranda

    Forme uma roda. Cante "Ciranda, Cirandinha" no ritmo normal — todos de mãos dadas girando para a direita. Esse é o loop externo.

  2. Insira o loop interno

    A cada trecho da música, a turma executa um gesto pequeno que se repete: levantar o braço direito 3 vezes. Enquanto o loop externo gira, o interno conta os gestos.

  3. Adicione a condição

    Quando o professor bater palmas, o sentido da roda inverte (SENÃO). A condição: "SE palma = girar para a direita; SENÃO = girar para a esquerda".

  4. Crie variações

    A turma propõe novas condições: agachar, trocar de lugar, acelerar. Cada nova regra é um bloco de código diferente.

  5. Reflita

    Pergunte: quantas vezes a roda girou completa? Quantos gestos foram feitos no total? Esse cálculo é o que um computador faz com contadores.

Dica para o professor Nomeie os loops em voz alta durante a brincadeira: "esse gesto que se repete é o nosso loop interno!"

Materiais

  • Espaço para a rodaPátio ou sala com mesas afastadas.
  • A cançãoCiranda Cirandinha, cantada pela turma.
  • Cartões de condiçãoOpcional, com os gestos escritos para consulta.

Conceito de computação

Loop aninhado é um laço de repetição dentro de outro. O loop externo controla a volta da roda; o interno controla os gestos dentro de cada volta.
